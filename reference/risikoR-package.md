# risikoR: Simulate, Analyse and Play the Board Game Risk

A toolkit for the board game Risk (German "Risiko"). Provides the
dice-combat engine, single-battle and whole-conquest simulators,
closed-form and Monte Carlo win probabilities, a full game state model
with a world map and adjacency graph, scriptable artificial-intelligence
agents, and a 'ggplot2' visualisation layer for maps, dice-duel outcomes
and probability curves. An interactive 'shiny' application supports
playing, simulating and analysing games. Combat resolution follows the
standard rules in which the attacker rolls up to three dice and the
defender up to two, comparing the highest dice pairwise with ties going
to the defender.
